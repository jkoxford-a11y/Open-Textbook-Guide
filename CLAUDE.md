# OER Project

## What this folder is

Working folder for a faculty-facing website that helps Columbia College faculty choose open textbooks (OER) for their courses. Two paths: **adopt** a good open text outright, or **remix** two or three with AI into a better one. The site needs a licenses page (what each license lets faculty do) and per-course options.

**Still to confirm:** course scope ("courses we teach") and how per-course options are stored and shown.

Site: plain HTML + `shared.css` (copied from Psych-AI-Pilot for a matching look). No build step. Local git only for now; no GitHub remote yet.

## Source material

- `Undergraduate+Catalog_combined.pdf`: CCIS undergraduate catalog (author Andrew Arth, file dated 2025-09-15). Why it's here is unconfirmed.

## Files

- `STATE.md`: current state, open decisions, and next steps. Read it first.
- `LOG.md`: dated log of what was decided and why. Append to it; don't rewrite it.
- `index.html`: start page (adopt vs. remix, where to look).
- `repositories.html`: open textbook collections and what's in each.
- `licenses.html`: CC licenses, remix rules, compatibility chart, attribution.
- `shared.css`: site styles.
