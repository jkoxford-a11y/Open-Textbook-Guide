Choosing an open textbook

For Columbia College faculty replacing a commercial textbook with open educational resources (OER).

Open textbooks are free for students and licensed so you can share them, and usually change them. There are two ways to use one.

Adopt

Use a strong existing open text as it is. This is the fastest path. Any open license allows it, including the ones that forbid changes.

Remix

Combine chapters from two or three open texts, with AI help, into a book that fits your course better. This only works with licenses that allow changes, and the sources' licenses must be compatible with each other.

Before you remix, read Licenses. It explains which licenses allow changes and which ones can be combined.

Where to look

These are the main open textbook collections. Each book lists its license.

  • OpenStax: peer-reviewed texts for high-enrollment intro courses.
  • Open Textbook Library: a large catalog with reviews written by faculty.
  • LibreTexts: many remixable texts. Licenses can differ from page to page, so check each chapter.
  • Noba: psychology modules you can assemble into a custom text.
  • OER Commons and OASIS: search tools that cover many collections at once.
